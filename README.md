# Python Data Structure Parser

## Overview

This project was developed as part of the **Advanced Fundamentals of Language and Logic (AFLL)** course during the 3rd semester.

The program parses input strings and identifies whether they represent valid Python data structures such as **dictionaries, lists, tuples, and sets**. It uses parsing techniques and Python programming concepts to analyze the structure and syntax of the given input.

## Features

- Identifies dictionary structures
- Detects list declarations
- Recognizes tuple structures
- Identifies set declarations
- Parses and analyzes input strings
- Demonstrates fundamental parsing and language-processing concepts

## Technologies Used

- **Python**
- Parsing and string-processing techniques
- Data structures

## Purpose

The project explores how programming languages interpret structured input and how parsing techniques can be used to identify different data structures from strings.

It provides practical implementation of concepts covered in the AFLL course, including syntax analysis, parsing, and language structure recognition.
